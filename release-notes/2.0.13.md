First releases of HomeLabControl 2.0: the web panel, the agent and ShutdownDialog in one repository, on .NET 10. Covers 2.0.0 – 2.0.13.

### Highlights
- **One config**: `config/HomeLabControl.yaml` with hosts and module sections, edited in the browser; the old per-module files are migrated on the first start.
- **Sign-in**: users with per-module permissions (`view` / `control`, `admin`), optional per-host restriction, audit log. The first administrator comes from `HLC_ADMIN_USER` / `HLC_ADMIN_PASSWORD`.
- **Agents**: grid with versions and health; deploy / update / update all / remove over SSH, automatic rollback if an update does not start. Agent builds are bundled into the image.
- **Agent API key**: one key per machine for HomeLabControl and Home Assistant. Swagger opens without a key; methods need **Authorize**.
- **Monitoring**: host page with a 24 h temperature chart; notifications to Telegram and/or MQTT: agent offline / online, SMART degradation, a fan profile that lost its sensor, failed backup.
- **Home Assistant via MQTT discovery**: devices with online status, temperatures, fans, disk problems, WoL / shutdown / reboot buttons.
- **Prometheus**: `/metrics` on every agent.
- **Backups**: scheduled push / pull backups of anything reachable over SSH (configs first), parallel limit, retention, history with logs.
- **Fan profiles**: status per profile (`ok` / sensor missing / fail-safe 100% / fan missing) in Fan Control and on the host page; a missing sensor is marked in the Edit dialog.
- **Without Docker**: self-contained builds of the server and the agent for Windows (service) and Linux (systemd) with install scripts; a hand-installed agent is added with **Add existing**.

### Upgrading from 1.x
- The first start merges `PowerControl.yaml`, `FanControl.yaml` and `BackupManager.yaml` into `HomeLabControl.yaml` (the old files are kept as `*.migrated`).
- The first deploy of the new agent over an old one generates an API key and closes the agent: add `X-Api-Key` with the key from **Config → Agents** to the Home Assistant `rest_command`.
- After updating LibreHardwareMonitor the disk sensor ids changed (`Storage__hdd_…`): open affected fan profiles and pick the sensor again — they are marked "Sensor missing — fan 100%".
